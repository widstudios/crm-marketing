# ⚡ QUICKSTART - Demo Online in 60 Secondi

## 🎯 Opzione 1: Replit (CONSIGLIATA)

### Passo 1: Accedi a Replit
https://replit.com

### Passo 2: Crea un nuovo Repl
1. Clicca "+ Create" (in alto a sinistra)
2. Seleziona "Git Repository"
3. Incolla: https://github.com/widstudios/crm-marketing
4. Clicca "Import from GitHub"

### Passo 3: Avvia
Clicca il bottone "▶ Run" in alto

### ✅ Fatto!
Dopo 30 secondi vedrai:
```
✅ Starting server on http://0.0.0.0:8000
📊 Dashboard: http://0.0.0.0:8000/dashboard.html
🔌 API: http://0.0.0.0:8000/api/v1
```

**Clicca sul link che appare a destra** - La demo è online! 🎉

## 🎯 Opzione 2: Docker

```bash
git clone https://github.com/widstudios/crm-marketing.git
cd crm-marketing
docker-compose up
```

Accedi a http://localhost:8000/dashboard.html
